# Set Effect

**Phase(s):** 2
**Confidence:** 0.7

## Definition

A set effect occurs when prior experience biases a problem solver to prefer certain operators or approaches, even when those approaches are suboptimal or inapplicable to the current problem. Set effects can be either facilitative (when the activated knowledge is appropriate) or inhibitory (when it is not). The term encompasses both procedural biases (being locked into a particular method) and declarative biases (having certain knowledge structures more available than others).

## Key Findings

- **Water jug problems** (Luchins, 1942): After practicing addition-solution problems, participants were faster on new addition problems but slower on subtraction problems compared to unpracticed controls ([[summary-2-09-anderson-ch8]])
- **Anagram solutions** (Safren, 1962): When anagrams in a list were semantically organized (all related to coffee), median solution time was 7.4 seconds vs. 12.2 seconds for unorganized lists -- associative priming facilitated problem solving
- The [[einstellung-effect]] is the most dramatic form of set effect
- Set effects can sometimes be dissipated easily: Luchins found that simply warning participants "Don't be blind" after problem 5 allowed more than 50% to overcome the set
- Set effects arise from both procedures (as in water jugs) and declarative knowledge (as in anagrams)

## Mechanisms

Prior problem solving activates certain knowledge structures (procedures or facts), making them more available for subsequent problems. If the activated knowledge matches what the new problem requires, performance is facilitated. If it does not match, the solver wastes effort applying inappropriate approaches and may fail entirely. The [[incubation-effect]] is best explained as the dissipation of inappropriate set effects over time.

## Applications

- When stuck on a problem, recognize that you may be trapped by a set from previous problems -- consciously try a completely different approach
- Warning yourself to "think differently" can be surprisingly effective at breaking set effects
- In teaching, be aware that practice sequences can create unhelpful sets if all problems use the same method
