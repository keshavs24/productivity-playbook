# Reference Dependence

**Phase(s):** 1, 2, 5
**Confidence:** 0.9

## Definition

Reference dependence is the principle that **people evaluate outcomes as gains or losses relative to a reference point**, rather than as absolute levels of wealth or welfare. The same objective state can be experienced as a gain or a loss depending on what the reference point is. This is "the cornerstone" of [[prospect-theory]].

## Key Findings

- Problems 11 & 12 demonstrate that the reference point (set by a bonus) determines what counts as a gain vs. a loss, reversing preferences for objectively identical final wealth states ([[summary-1-02-prospect-theory]])
- The reference point is usually the current asset position (status quo), but it can be shifted by expectations, aspirations, social comparison, or framing
- The analogy to perception is precise: just as temperature is perceived relative to adaptation level (the same water feels hot or cold depending on what you adapted to), value is perceived relative to the reference point

## Mechanisms

The perceptual system is designed to detect *changes*, not absolute levels. This applies to brightness, temperature, pressure, and — the paper argues — to value/utility. The reference point functions as an "adaptation level" from which deviations are measured. Everything above it is a gain; everything below is a loss. This is efficient (changes are often more important than levels) but creates predictable biases when the reference point is manipulated.

## Applications

- **Negotiation (Phase 5):** Each party's reference point determines what feels like a gain vs. a concession (loss). Shifting someone's reference point — through anchoring, framing, or expectations management — can transform the same deal from feeling like a loss to feeling like a gain.
- **Salary/compensation:** A $5,000 raise feels like a gain from current salary but might feel like a loss if the employee expected $10,000. The reference point (expectation) determines the psychological valence.
- **Pricing:** A price increase from an established price feels like a loss; the same final price as an introductory offer feels like a gain.
- **Goal-setting:** Goals function as reference points. Falling short of a goal (loss) feels worse than the equivalent amount of exceeding it (gain) feels good.

## Bazerman & Moore Extensions (Chapters 5-6)

Bazerman and Moore ([[summary-2-08-bazerman-ch5]], [[summary-2-08-bazerman-ch6]]) add key applications:

- **Stock reference point problem:** XYZ stock dropped from $20 to $10. If your reference point is $0 (what you received the stock for), you are in gain territory and will be risk averse (sell). If your reference point is $20 (what the stock was worth), you are in loss territory and will be risk seeking (hold). The reference point determines the decision.
- **Ownership as reference point shift:** The [[endowment-effect]] occurs because owning an item shifts the reference point to include it. Selling becomes a loss from the new reference point, explaining the 2:1 ownership-to-valuation ratio.
- **Transactional utility:** Expected "fair prices" serve as reference points for evaluating deal quality. Identical beer is worth $2.65 from a resort hotel but $1.50 from a grocery store because the reference price differs.
- **Evolutionary explanation:** Rayo and Becker (2007) argue reference dependence is adaptive -- the limited sensitivity of the subjective utility scale requires reference point readjustment to maintain motivation, creating the hedonic treadmill.
